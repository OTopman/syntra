Context

Since v0.1.0

HTTP execution context encapsulating the incoming client request and outgoing response.

Context provides ergonomic helper methods for URL parameters, query strings, request headers, JSON serialization, Server-Sent Events (SSE), and fluent response construction.

Example

syntra 
app.get("/users/:id", (Context ctx) => {
    string id = ctx.param("id");
    ctx.json("{\"id\": \"" + id + "\", \"status\": \"active\"}");
});

Fields

FieldTypeAccessDescription
req HttpRequest public The incoming parsed HTTP client request.
res HttpResponse public The outgoing HTTP response being assembled.
params Map public Extracted path parameters matching dynamic pattern segments (e.g. ":id").
queryParams Map public Parsed query string key-value pairs (e.g. "?page=1&limit=20").
isHandled bool public Flag indicating whether a terminal response has already been committed to the context.

WebSocket

Since v0.1.0

Full-duplex RFC 6455 compliant WebSocket connection over TCP stream.

Supports server and client frame masking, unmasking, non-blocking asynchronous reading, broadcast distribution, and channel-based event delivery.

Example

syntra 
app.ws("/chat", (WebSocket ws) => {
    ws.send("Welcome to Syntra Realtime!");
    string msg = ws.read();
});

Fields

FieldTypeAccessDescription
stream TcpStream public Underlying TCP network socket stream.
isOpen bool public Boolean flag indicating whether the socket handshake completed and remains open.
id string public Unique session connection identifier.
attributes Map public User-defined connection attributes and session metadata.
channel Channel public Asynchronous channel for queuing incoming WebSocket frames.

Supports fluent builder chaining to configure tags, summaries, request schemas, response codes, and route-level middlewares.

class

App

Since v0.1.0

High-level web application and server container.

Provides expressive route registration (get, post, put, delete, ws), global middleware chains, integrated OpenAPI/Swagger UI endpoints, and asynchronous event loop server.

Example

syntra 
App app = new App();
app.enableSwagger("/docs");
app.get("/api/v1/ping", (Context ctx) => {
    ctx.json("{\"status\": \"healthy\"}");
});
app.listen(8080);

Fields

FieldTypeAccessDescription
router Router public Internal Radix Router managing URL pattern dispatching.
openApiPath string public Endpoint path serving the generated OpenAPI 3.0 specification.
swaggerPath string public Endpoint path serving the embedded Swagger UI interactive documentation viewer.
openApiEnabled bool public Whether the automatic OpenAPI specification endpoint is enabled.
swaggerEnabled bool public Whether the embedded Swagger UI viewer endpoint is enabled.
globalMiddlewares any[] public Global middleware pipeline executed sequentially on every incoming request.
wsRoutes Map public Table of registered WebSocket endpoints and connection upgrade handlers.
