system

OS Primitives & Environment

Provides command-line arguments, environment variables, time, and exit controls.

namespace

System

The System namespace provides foundational operating system primitives, process lifecycle management, standard console I/O, execution timers, and access to the host environment.

All functions in this namespace interface directly with the runtime kernel without intermediate allocation overhead.

syntra 
import System;

func main(): void {
    System.println("Application started at " + System.timeMs() + " ms");
    let user = System.getEnv("USER");
    System.println("Running as user: " + user);
}

func args() -> string[]

Retrieves the array of command-line arguments passed to the program upon invocation.

The first entry typically represents the active binary or executed script path, followed by any user-supplied flags, arguments, and switches.

syntra 
let args = System.args();
for arg in args {
    System.println("Arg: " + arg);
}
Returns

string[] — An array of strings representing command-line arguments.

func exit(int code) -> void

Terminates the calling process immediately with the specified exit code.

Conventionally, an exit code of 0 denotes clean, successful termination, while non-zero codes indicate errors or abnormal abort conditions.

syntra 
if (!isValid) {
    System.println("Fatal validation error.");
    System.exit(1);
}

code int Operating system process return code (0 for success, >0 for errors).

func getEnv(string key) -> string

Reads an environment variable by name from the current process environment.

If the environment variable is unset or inaccessible, this function returns an empty string ("") rather than throwing an exception.

syntra 
let path = System.getEnv("PATH");
let port = System.getEnv("PORT");
Parameters
NameTypeDescription
key string The case-sensitive name of the environment variable to look up.
Returns

string — The string value of the environment variable, or "" if unset.

func timeMs() -> int

Returns the current Unix epoch time in milliseconds.

Measures monotonic wall-clock elapsed time since 00:00:00 UTC, January 1, 1970.

syntra 
let start = System.timeMs();
doComputation();
let elapsed = System.timeMs() - start;
System.println("Duration: " + elapsed + " ms");
Returns

int — 64-bit integer timestamp in milliseconds.

func exec(string cmd) -> int

Spawns a subshell process executing the specified command and returns its termination exit code.

Blocks the current fiber until the child process terminates.

syntra 
let status = System.exec("git status --short");
if (status != 0) {
    System.println("Git command failed.");
}
Parameters
NameTypeDescription
cmd string The shell command string to execute.
Returns

int — Process exit status code returned by the OS.
