air

Intermediate Representation

Conforms to Specification 03: AIR-001 - AIR-032. Implements SSA Intermediate Representation generation, block branching, and AIR serialization in Syntra.

class

AirValue

Since v0.1.0

SSA Value Identifier (e.g. v0, v1, v2).

Every value in AIR represents an immutable single-assignment static single-assignment (SSA) register.

Example

syntra 
AirValue v = new AirValue(0, Type.Int());
println(v.toString()); // "v0"

Fields

FieldTypeAccessDescription

class

AirLowering

Since v0.1.0

AIR Lowering Engine: converts type-checked AST nodes to SSA AIR modules.

Performs control-flow graph construction, basic block splitting for if and while statements, variable versioning, and expression linearization into three-address SSA instructions.

Example

syntra 
AirLowering lowering = new AirLowering(checker, "main");
AirModule air = lowering.lowerProgram(ast);
println(air.toString());

Fields

FieldTypeAccessDescription
checker TypeChecker public TypeChecker providing semantic metadata and symbol tables.
module AirModule public Target module being populated.
nextValueId int public Generator counter for unique SSA value IDs.
nextBlockId int public Generator counter for unique CFG block IDs.
currentBlock AirBlock public Currently active basic block receiving instructions.
varBindings SsaVar[] public Active variable bindings table for SSA register resolution.
