class

MapEntry

Since v0.1.0

Generic key-value pair container representing an entry in a Map.

Encapsulates immutable key references and associated values.

syntra 
let entry = new MapEntry<string, int>("counter", 42);
System.println("Key: " + entry.getKey() + " -> " + entry.getValue());
