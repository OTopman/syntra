HttpRequest

Since v0.1.0

Represents an incoming or outgoing HTTP/1.1 request message.

Encapsulates the HTTP verb (method), request target URI path, HTTP version, key-value header mappings, and payload body.

syntra 
let req = new HttpRequest();
req.method = "POST";
req.path = "/api/v1/users";
req.headers.set("Content-Type", "application/json");
req.body = "{\"name\":\"Alex\"}";

Fields

FieldTypeAccessDescription
method string public The HTTP verb string (e.g. "GET", "POST", "PUT", "DELETE", "PATCH", "OPTIONS").
path string public The target URI resource path (e.g. "/index.html" or "/api/data").
version string public The HTTP protocol version string (conventionally "HTTP/1.1").
headers Map public Case-insensitive key-value map of HTTP headers.
body string public UTF-8 encoded request payload body.

func parse(string raw) -> HttpRequest

Parses a raw wire-format HTTP request string into a structured HttpRequest instance.

Deconstructs request line, headers, and body according to RFC 7230.

syntra

let req = HttpRequest.parse(raw);

HttpServer

Since v0.1.0

A high-performance, asynchronous HTTP server.

Listens on a local TCP port, accepts incoming client connections, parses requests, and transmits formatted responses.

syntra 
let server = new HttpServer();
server.listen(8080);
System.println("Serving on port 8080");

while (true) {
    let client = server.accept();
    let res = HttpResponse.ok("Hello from Syntra!", "text/plain");
    server.sendResponse(client, res);
}

HttpClient

Since v0.1.0

Synchronous HTTP client utility for making outgoing HTTP requests.

Supports all standard HTTP verbs with automatic connection teardown.

syntra 
let res = HttpClient.get("example.com", 80, "/");
System.println("Status: " + res.statusCode);
System.println("Body: " + res.body);
