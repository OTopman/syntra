email

Email & MIME Engine

Enterprise-grade, RFC-compliant email composition, MIME serialization, inbound parsing, DKIM canonicalization, SMTP client, Cloud REST API transports, and in-memory test runner. Standards compliant: - RFC 5321: Simple Mail Transfer Protocol (SMTP client, EHLO, AUTH LOGIN/PLAIN) - RFC 5322: Internet Message Format (Headers, Date, Message-ID, Address specs) - RFC 2045/2046/2047: MIME Multipart, Attachments, UTF-8 Encoded-Words - RFC 6376: DomainKeys Identified Mail (DKIM) Canonicalization & Body Hashing - RFC 4648: Base64 Content-Transfer-Encoding for binary attachments

EmailAddress

Since v0.1.0

Represents a validated, structured RFC 5322 email address (display name and addr-spec).

Handles formatting and parsing of address strings like "Alice Smith <alice@example.com>" or bare addresses like "alice@example.com". Automatically sanitizes CRLF sequences to eliminate SMTP header injection vulnerabilities.

Example

syntra 
let addr = EmailAddress.parse("Alice Smith <alice@example.com>");
System.println("Name: " + addr.name);       // "Alice Smith"
System.println("Email: " + addr.address);   // "alice@example.com"
System.println("Formatted: " + addr.format()); // "Alice Smith <alice@example.com>"

Fields

name string public Optional human-readable display name (e.g. "Alice Smith").
address string public The mailbox address specification (e.g. "alice@example.com").

EmailAttachment

Since v0.1.0

Represents an email attachment or embedded inline MIME body part.

Supports binary files (encoded via RFC 4648 Base64) and text payloads. Can be referenced in HTML templates via Content-ID (cid:imageId).

Example

syntra

let img = EmailAttachment.inline("logo", "logo.png", b64Data, "image/png");

EmailMessage

Since v0.1.0

Fluent builder and container for composing RFC 5322 email messages.

Supports multiple recipients (to, cc, bcc), replyTo, subject sanitization, HTML body, plain text alternative body, custom headers, attachments, and template merging.

Example

syntra 
let msg = EmailMessage.create()
    .from("support@myapp.com", "My App Support")
    .to("alice@example.com", "Alice")
    .subject("Your Monthly Report")
    .html("<h1>Monthly Report</h1><p>See attached summary.</p>")
    .text("Monthly Report: See attached summary.")
    .attachText("summary.csv", "id,item,cost\n1,Pro Plan,49.00", "text/csv");

Fields

FieldTypeAccessDescription
from EmailAddress public Originating sender address.
to EmailAddress[] public Primary recipient addresses.
cc EmailAddress[] public Carbon copy recipient addresses.
bcc EmailAddress[] public Blind carbon copy recipient addresses (excluded from outgoing MIME headers).
replyTo EmailAddress public Optional Reply-To destination address.
subject string public Message subject header line (CRLF sanitized).
text string public Plain text fallback email body.
html string public HTML formatted email body.
headers Map public Custom email headers map (e.g. X-Priority, X-Entity-ID).
attachments EmailAttachment[] public List of file and inline attachments.
messageId string public Globally unique Message-ID header (e.g. <12345.67890@domain.com>).
date string public Creation timestamp string.

Decodes raw .eml files or inbound webhooks (from SendGrid, AWS SES, Postmark, Mailgun) into structured EmailMessage models, extracting headers, text, HTML, and base64 attachments.

DkimConfig

Since v0.1.0

RFC 6376 DomainKeys Identified Mail (DKIM) Canonicalization and Verification Engine.

Implements relaxed/relaxed and simple/simple canonicalization, SHA-256 body hashing (bh=), and builds RFC 6376 compliant DKIM-Signature header fields.

Example

syntra 
let dkim = new DkimConfig("s1", "example.com", "rsa_private_key_pem");
string bodyHash = dkim.computeBodyHash(msg.text, "relaxed");
string dkimHeader = dkim.formatHeader("from:to:subject:date", bodyHash, "sig_b64");

Fields

FieldTypeAccessDescription
selector string public DKIM DNS selector tag (s=).
domain string public Signing domain tag (d=).
privateKey string public Signing private key (PEM or hex).
canonicalization string public Canonicalization algorithm (e.g. "relaxed/relaxed" or "simple/simple").

SmtpTransport

Since v0.1.0

High-performance RFC 5321 SMTP client transport.

Connects via raw TCP sockets, negotiates EHLO, performs AUTH LOGIN or AUTH PLAIN credentials exchange, handles recipient routing, streams MIME payloads, and incorporates exponential backoff retry resiliency for transient errors.

Example

syntra 
let smtp = SmtpTransport.of("smtp.mailgun.org", 587, "user", "secret");
if (smtp.verify()) {
    let res = smtp.send(msg);
}

Fields

FieldTypeAccessDescription
host string public Remote SMTP relay server hostname or IP address (e.g. "smtp.mailgun.org").
port int public Remote SMTP TCP port (conventionally 587 for submission, 465 for SMTPS, 25 for relay).
username string public SMTP authentication username.
password string public SMTP authentication password.
maxRetries int public Maximum retry attempts on transient network errors.
retryDelayMs int public Initial delay in milliseconds for exponential backoff retries.
