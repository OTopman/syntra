class

JsonHelper

Since v0.1.0

Helper utilities for JSON serialization and parsing of Syntra objects, arrays, and key-value maps.

Built on top of the native high-speed JSON serialization engine.

syntra 
let data = new Map<string, string>();
data.set("name", "syntra");
data.set("version", "0.1.0");

let json = JsonHelper.stringifyMap(data);
System.println("JSON: " + json);

func parseMap(string jsonStr) -> Map

Parses a JSON formatted string into a Syntra Map representation.

syntra 
let raw = "{\"host\":\"localhost\",\"port\":\"8080\"}";
let map = JsonHelper.parseMap(raw);
System.println("Host: " + map.get("host"));
