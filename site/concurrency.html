func sleepMs(int ms) -> void

Suspends execution of the current fiber or thread for the specified duration.

Yields CPU execution to other concurrent fibers during the sleep period.

syntra 
System.println("Pausing for 500ms...");
sleepMs(500);
System.println("Resumed.");
Parameters
NameTypeDescription
ms int Sleep duration in milliseconds.
Returns

void — void

func createChannel() -> Channel

Creates a new unbounded FIFO synchronization channel for message passing.

Channels provide thread-safe communication between concurrent tasks without shared-memory synchronization locks.

syntra 
let ch = createChannel();
Task.spawn(fn() {
    ch.send("Worker message");
});
let response = ch.recv();
Returns

Channel — A new Channel instance.

func createThreadPool(int workers) -> ThreadPool

Creates a bounded worker thread pool for parallel CPU-bound compute tasks.

Worker threads are pooled and reused across tasks, eliminating thread creation overhead.

syntra 
let pool = createThreadPool(4);
for i in 0..10 {
    pool.submit(fn() {
        computeItem(i);
    });
}
pool.wait_idle();
Parameters
NameTypeDescription
workers int Number of dedicated background execution threads.
Returns

ThreadPool — A new ThreadPool instance.

func selectChannels(Channel[] channels) -> int

Non-blocking multiplexer over an array of channels.

Inspects the provided channels and returns the zero-based integer index of the first channel that contains an available message ready for receiving.

syntra 
let ch1 = createChannel();
let ch2 = createChannel();
ch2.send("Alert");

let readyIndex = selectChannels([ch1, ch2]);
if (readyIndex == 1) {
    let msg = ch2.recv();
    System.println("Received: " + msg);
}
Parameters
NameTypeDescription
channels Channel[] Array of Channel instances to poll.
Returns

int — Zero-based index of the ready channel, or -1 if none ready.
