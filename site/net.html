func listen(int port) -> TcpListener

Binds a TCP listener socket to the specified local port.

Listens for incoming TCP connections on all local network interfaces (0.0.0.0).

syntra 
let listener = listen(8080);
System.println("Listening for connections on port 8080...");
let stream = listener.accept();
Parameters
NameTypeDescription
port int Local TCP port number to bind (1-65535).
Returns

TcpListener — A TcpListener instance listening on the given port.

func connect(string host, int port) -> TcpStream

Establishes an active outgoing TCP stream connection to host:port.

Performs DNS resolution and initiates the TCP three-way handshake.

syntra 
let stream = connect("127.0.0.1", 8080);
stream.write("GET / HTTP/1.1\r\nHost: localhost\r\n\r\n");
let response = stream.readText();
Parameters
NameTypeDescription
host string Hostname or IP address string (e.g. "127.0.0.1" or "api.example.com").
port int Remote TCP port number to connect to.
Returns

TcpStream — An active connected TcpStream handle.

func serveHttpReactor(int port, int workers) -> int

Launches the native high-performance multi-core HTTP reactor.

Uses kernel event notification (kqueue on macOS/BSD, epoll on Linux) to distribute incoming HTTP requests across worker threads with zero-copy I/O.

syntra 
// Launch HTTP reactor on port 8080 across 4 worker threads
serveHttpReactor(8080, 4);
Parameters
NameTypeDescription
port int Port number to listen on.
workers int Number of dedicated reactor worker threads.
Returns

int — Status return code (0 for normal exit).
