Cryptography

100% Pure Syntra Implementation with ZERO external C or OpenSSL dependencies. Standards compliant: - SHA-256: FIPS PUB 180-4 Secure Hash Standard - HMAC-SHA256: RFC 2104 Keyed-Hashing for Message Authentication - Hex & Base64: RFC 4648 Encoders & Decoders - SecureRandom: Cryptographically secure entropy source - ConstantTime: Timing-attack resistant operations

class

Hex

Since v0.1.0

High-performance hexadecimal serialization and deserialization utilities.

Encodes raw binary byte arrays into lowercase hexadecimal strings and parses valid hex strings back to byte sequences.

Example

syntra 
string hex = Hex.encode([0xde, 0xad, 0xbe, 0xef]); // "deadbeef"
int[] bytes = Hex.decode("deadbeef");

HmacSha256

Since v0.1.0

RFC 2104 HMAC-SHA256 Keyed-Hashing for Message Authentication.

Produces cryptographically validated message authentication codes (MACs) using a shared secret key and SHA-256.

Example

syntra 
string signature = HmacSha256.compute("secret-key", "data-payload");
bool valid = HmacSha256.verify("secret-key", "data-payload", signature);

SecureRandom

Since v0.1.0

Cryptographically Secure Pseudorandom Number Generator (CSPRNG).

Implements Hash_DRBG-style entropy pooling based on nanosecond timers, process metrics, and SHA-256 state folding for generating cryptographically robust session tokens and salts.

Example

syntra 
string token = SecureRandom.hex(16); // 32-character hex token (128 bits)
int[] randomBytes = SecureRandom.bytes(32);
