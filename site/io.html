func fileExists(string path) -> bool

Check whether a file or directory exists on the filesystem at the given path.

Performs a non-throwing filesystem metadata query.

syntra 
if (fileExists("config/settings.json")) {
    let conf = readFile("config/settings.json");
}
Parameters
NameTypeDescription
path string Filesystem path string (relative to workspace or absolute).
Returns

bool — true if target path exists and is accessible; false otherwise.

func readFile(string path) -> string

Reads the entire contents of a file into a UTF-8 string.

Opens the target file in read-only mode and reads all bytes to completion.

syntra 
try {
    let content = readFile("data/input.txt");
    System.println("File length: " + content.length());
} catch (err) {
    System.println("Failed to read: " + err);
}
Parameters
NameTypeDescription
path string Target filesystem path.
Returns

string — The decoded UTF-8 string contents of the file.

func writeFile(string path, string content) -> bool

Writes string text contents to a target file on disk.

If the file already exists, it is truncated and replaced. If it does not exist, it is created with standard permissions.

syntra 
let success = writeFile("logs/app.log", "Initialized application.\n");
if (success) {
    System.println("Log recorded.");
}
Parameters
NameTypeDescription
path string Target filesystem path to write.
content string UTF-8 string data to write.
Returns

bool — true if write succeeded; false if an error occurred.

Since v0.1.0

func appendFile(string path, string content) -> bool

Appends string text contents to the end of a file on disk.

If the file does not exist, it is created. Preserves all existing file contents.

syntra 
appendFile("logs/audit.log", "User logged in at " + System.timeMs() + "\n");
Parameters
NameTypeDescription
path string Target filesystem path to append.
content string UTF-8 string payload to append.
Returns

bool — true on successful append; false otherwise.

func deleteFile(string path) -> bool

Deletes a file from the filesystem.

Permanently unlinks the target file path.

syntra 
if (fileExists("temp/cache.bin")) {
    deleteFile("temp/cache.bin");
}
Parameters
NameTypeDescription
path string Target filesystem path to remove.
Returns

bool — true if file was successfully deleted; false otherwise.

func fileSize(string path) -> int

Retrieves the size of a file in bytes.

Returns -1 if the file does not exist or metadata cannot be retrieved.

syntra 
let bytes = fileSize("assets/image.png");
if (bytes > 0) {
    System.println("Asset size: " + bytes + " bytes");
}
Parameters
NameTypeDescription
path string Target filesystem path to inspect.
Returns

int — 64-bit integer file size in bytes, or -1 on error.
