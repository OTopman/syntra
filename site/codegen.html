codegen

Cranelift Code Generation

Translates Syntra AIR (SSA Intermediate Representation) into native machine assembly (x86-64 / AMD64 System V ABI). Fully self-hosting, zero external dependencies, operating within Arena memory domains.

AsmInstruction

Since v0.1.0

Native Assembly Instruction representation.

Encapsulates mnemonic, destination operand, and source operand formatted for Intel syntax.

Example

syntra 
AsmInstruction inst = new AsmInstruction("mov", "rax", "42");
println(inst.toString()); // "    mov rax, 42"

class

NativeCodegen

Since v0.1.0

Self-Hosting Native Machine Code Generator.

Translates SSA AIR basic blocks and instructions into x86-64 / AMD64 System V assembly code.

Features:

  • Register allocation / stack spilling
  • System V AMD64 calling convention argument passing (rdi, rsi, rdx, rcx, r8, r9)
  • 16-byte stack frame alignment
  • Mach-O / ELF interoperability

Example

syntra 
NativeCodegen codegen = new NativeCodegen(airModule);
string asm = codegen.generateModule();
File.writeText("out.s", asm);

Fields
