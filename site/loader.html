Dynamic Module Loader

Provides recursive multi-file dependency resolution, AST splicing, circular dependency prevention, and search path resolution for self-hosting.

class

ModuleLoader

Since v0.1.0

Pure Syntra Module Loader & Dependency Resolver.

Resolves and loads multi-file Syntra packages recursively, parsing imports into AST nodes, preventing circular dependencies, managing package search paths, and performing AST splicing.

Example

syntra 
Arena arena = new Arena();
ModuleLoader loader = new ModuleLoader(arena);
loader.addSearchPath("./vendor");
AstNode rootAst = loader.loadProgram("src/main.syn");

Fields

FieldTypeAccessDescription
loadedFiles string[] public List of canonical file paths that have already been resolved and parsed to prevent cycles.
searchPaths string[] public Ordered search directory paths inspected when resolving imports without relative slashes.
arena Arena public Memory arena used for allocating AST nodes during parsing.
