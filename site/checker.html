Type

Since v0.1.0

Type representation in the Syntra semantic model.

Encapsulates primitive types (int, float, bool, string, void), user-defined class references, array dimensions (T[]), and subtyping compatibility checks.

Example

syntra 
Type intTy = Type.Int();
Type arrTy = Type.Array(intTy);
println(arrTy.toString()); // "int[]"

Fields

FieldTypeAccessDescription
kind string public Type discriminator kind ("int", "float", "bool", "string", "void", "class", or "unknown").
name string public Class symbol name if kind is "class", otherwise empty string.
isArray bool public True if this represents an array collection type: T[].

class

TypeChecker

Since v0.1.0

Syntra Self-Hosting Type Checker and Semantic Analyzer (Specification 01: LANG-020).

Executes two-pass semantic analysis:

  • Pass 1 (collectSymbols): Discovers and registers global functions, classes, and fields.
  • Pass 2 (checkProgram): Type checks statements, expressions, control flow, assignments, and returns.

Example

syntra 
TypeChecker checker = new TypeChecker();
checker.checkProgram(ast);
if (checker.hasErrors()) {
    println("Errors: " + checker.errorCount());
}

Fields

FieldTypeAccessDescription
scopeStack Scope[] public Active lexical scope stack frames.
functions FnSymbol[] public Global functions registry.
classes ClassSymbol[] public Global classes registry.
diagnostics Diagnostic[] public Diagnostic errors accumulated during analysis.
currentReturnType Type public Expected return type of the function currently being checked.
currentClassName string public Name of the class currently being checked, or empty if in global scope.
