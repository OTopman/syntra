syntax

AST & Lexer Engine

Provides a zero-GC self-hosting Lexer, AST, and recursive-descent Parser utilizing Syntra Memory Domains (Scoped Arenas) for high-performance compilation.

class

Span

Since v0.1.0

Source code location span tracking byte offsets, 1-based line, and 1-based column coordinates.

Attached to tokens, AST nodes, and compiler diagnostics for error reporting and IDE navigation.

Example

syntra 
Span span = new Span(0, 10, 1, 1);
println(span.toString()); // "1:1"

Fields

FieldTypeAccessDescription
start int public 0-based start byte offset in the source buffer.
end int public 0-based end byte offset in the source buffer.
line int public 1-based source line number.
col int public 1-based source column offset.

AstNode

Since v0.1.0

Abstract Syntax Tree (AST) node allocated within an Arena memory domain.

Represents syntactical constructs (Programs, Functions, Classes, Expressions, Statements).

Example

syntra 
AstNode node = new AstNode("IntLit", "42", 42, span);
println(node.toSExpr());

name string public Identifier name or literal text payload.
intVal int public Pre-parsed integer value for numeric literals.
children AstNode[] public Ordered children AST nodes.
span Span public Source code location span covering this syntactic construct.

Lexer

Since v0.1.0

High-performance Syntra Lexer.

Scans UTF-8 source text and produces a linear stream of strongly typed tokens. Handles comments (//, /* */), integer literals, string escapes, keywords, and operators.

Example

syntra 
Lexer lexer = new Lexer("func add(int a, int b): int { return a + b; }");
Token[] tokens = lexer.tokenize();

Fields

FieldTypeAccessDescription
src string public Raw source text string.
pos int public Current scanning cursor byte index.
len int public Total byte length of source text.
line int public Current 1-based source line.
col int public Current 1-based source column.

class

Parser

Since v0.1.0

Recursive-Descent Parser allocating AST nodes in an Arena Memory Domain.

Implements standard precedence climbing for expressions and parses declarations, classes, interfaces, namespaces, imports, and statements.

Example

syntra 
Arena arena = new Arena();
Parser parser = new Parser(tokens, arena);
AstNode ast = parser.parseProgram();

Fields

FieldTypeAccessDescription
tokens Token[] public Array of input tokens produced by the lexer.
pos int public Current token stream index cursor.
count int public Total count of input tokens.
arena Arena public Scoped memory arena allocating AST node lifetimes.
